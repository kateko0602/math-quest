# 숙제 대소동 (가칭) — 초등 수학 숙제 게임 웹앱 · 시제품 v0.5

초등 수학 학원 숙제를 **폰에서 30초에 채점하고 사진 한 장으로 제출**하는 게임형 웹앱 시제품입니다.
세계관은 **〈숫자 왕국 구출 대작전〉** — 알은 딱 하나, **펫 알**.
**못 고친 오답**을 다시 풀어 **⚔️ 해결!**하면 **펫 알이 부화**해 펫이 내 도감에 들어옵니다.
정적 파일만으로 동작하며(빌드 없음), 인터넷 주소로 바로 열 수 있습니다.

- **바로 열기**: https://kateko0602.github.io/math-quest/
- **체험 PIN** — 학생 `1234` · 선생님 `2580`
- 데이터는 이 브라우저(`localStorage`)에만 저장되는 **테스트 모드**입니다. (관리시트 연동 예정)
- 예시 학생 이름·반 이름은 모두 샘플입니다.

## 동선

1. 반 → 내 이름 → PIN 4자리 (회원가입 없음)
2. **① 채점** — 맞은 문제 `⭕`, 틀린 문제 `❌`(‘왜 틀렸나요?’ 태그는 선택). 두 교재면 위 탭으로 전환
3. **② 정리 · 사진** — 틀린 문제마다 `⚔️ 해결!(펫 알 부화)` / `⭐ 질문`, 오늘 뽑힌 1쪽 사진(미리보기 확인) → 제출
4. **③ 완료** — 폭죽 + 코인 + 칭호 + 보스 데미지 (+ 안 푼 문제는 바로 밀린문제로)

## 화면

- 아이: **숙제**(오늘 숙제·오답프린트·밀린문제 탭) · **내 도감**(자주 하는 실수 · 펫 도감 · 못 고친 오답 · 불꽃 달력 · 단원평가) · **랭킹**
- 설정(⚙️): 캐릭터·닉네임, 소리, PIN 바꾸기, 이야기, 선생님 모드, 로그아웃
- 선생님(PIN `2580`): **오늘**(제출 확인·한꺼번에 도장 + 학생 목록) · **질문** · **성취도** · **⚙️ 관리**(오늘 진도, 프린트 설정, 현실 보상 쿠폰, 친구들 풀이 공개, 테스트 도구, 쪽수표, 학생·PIN)
