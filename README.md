## 동선

1. 반 → 내 이름 → PIN 4자리 (회원가입 없음)
2. **① 채점** — 맞은 문제 `⭕`, 틀린 문제 `❌`. 두 교재면 위 탭으로 전환
3. **② 정리 · 사진** — 틀린 문제마다 `⚔️ 고쳤어요` / `⭐ 또 틀림·질문`, 오늘 뽑힌 1쪽 사진 → 제출
4. **③ 완료** — 폭죽 + 코인 + 칭호 + 보스 데미지
