# 숙제 대소동 (가칭) — 초등 수학 숙제 게임 웹앱 · 시제품 v0.2

초등 수학 학원 숙제를 **폰에서 30초에 채점하고 사진 한 장으로 제출**하는 게임형 웹앱 시제품입니다.
정적 파일만으로 동작하며(빌드 없음), 인터넷 주소로 바로 열 수 있습니다.

- **바로 열기**: https://kateko0602.github.io/math-quest/
- **체험 PIN** — 학생 `1234` · 선생님 `2580`
- 데이터는 이 브라우저(`localStorage`)에만 저장되는 **테스트 모드**입니다. (관리시트 연동 예정)
- 예시 학생 이름·반 이름은 모두 샘플입니다.

## v0.2에서 달라진 점

| 항목 | v0.1 | v0.2 |
| --- | --- | --- |
| 채점 | 문제 타일 0/1/2/3 토글 | 문제마다 **`⭕ 맞음` / `❌ 틀림` 두 버튼** (같은 버튼 다시 누르면 해제) |
| 안 푼 문제 | '어디까지 풀었나요' 끝번호 선택 | **아무것도 안 누르면 미풀이** → 내일 자동 이월 |

| 뒤로가기 | 제출 화면에서 되돌아갈 수 없음 | 사진·제출 단계 어디서든 **`← 뒤로 (채점 고치기)`** |
| 홈 | 카드가 많음 | 오늘 진도·숙제 · 보스 HP · **큰 채점 시작 버튼**만 |
| 저장 | 토글 시 저장 | 누르는 즉시 저장 + **하던 단계까지 복원**(새로고침·재접속해도 이어짐) |

## 동선

1. 반 → 내 이름 → PIN 4자리 (회원가입 없음)
2. **① 채점** — 맞은 문제 `⭕`, 틀린 문제 `❌`. 전부 풀었으면 `⭕ 모두 맞음` 한 번
3. **② 정리 · 사진** — 틀린 문제마다 `⚔️ 고쳤어요` / `⭐ 또 틀림·질문`, 사진 촬영 → 제출
4. **③ 완료** — 폭죽 + 오늘의 칭호, 보스 데미지

- 아이: 오늘 숙제 · 내 기록(오답 몬스터 도감·불꽃 달력) · 랭킹 2종 · 내 정보
- 선생님(PIN `2580`): 오늘 현황(⭕/❌/⚔️/⭐/⏭️) · 도장 · 질문 TOP 5 · 쪽수표 · 학생·PIN
