# 숙제 대소동 — 초등 수학 숙제 게임 웹앱 · v1.2

초등 수학 숙제를 **폰에서 30초에 채점하고 사진 한 장으로 제출**하는 게임형 웹앱입니다.
세계관은 **〈숫자 왕국 구출 대작전〉** — 알은 딱 하나, **펫 알**.
**못 고친 오답**을 다시 풀어 **⚔️ 해결!**하면 **펫 알이 부화**해 펫이 내 도감에 들어오고,
이제 **문제를 풀수록 펫이 3단계까지 자랍니다.**

- **바로 열기**: https://kateko0602.github.io/math-quest/
- **체험 PIN** — 학생 `1234` · **선생님 PIN은 첫 접속 때 4자리로 직접 정합니다** (코드·화면·README에 없습니다)
- 데이터는 이 브라우저에만 저장되는 **테스트 모드**입니다.
- 연습용으로 따로 쌓고 싶으면 주소 뒤에 **`?mode=demo`**를 붙이세요. 운영 데이터와 섞이지 않습니다.
- 예시 학생 이름·반 이름은 모두 샘플입니다.

## 동선 (아이는 5초 컷)

1. 반 → 내 이름 → PIN 4자리 (회원가입 없음)
2. **① 채점** — 수업에서 푼 부분은 `🏫 몇 번부터`로 접고, **틀린 것만 ❌** 누른 뒤 아래 고정 바의 **`✨ 나머지 전부 ⭕`** 한 번. 맞았지만 궁금하면 `⭐`
3. **② 정리 · 사진** — 오답 `⚔️ 해결!(펫 알 부화)` / `⭐ 질문`, 오늘 뽑힌 1쪽 사진(미리보기 확인) → 제출
4. **③ 완료** — 폭죽 + 코인 + XP + 미션 달성 + 보스 데미지
