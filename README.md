# 숙제 대소동 — 초등 수학 숙제 게임 웹앱 · v1.0

초등 수학 숙제를 **폰에서 30초에 채점하고 사진 한 장으로 제출**하는 게임형 웹앱입니다.
세계관은 **〈숫자 왕국 구출 대작전〉** — 알은 딱 하나, **펫 알**.
**못 고친 오답**을 다시 풀어 **⚔️ 해결!**하면 **펫 알이 부화**해 펫이 내 도감에 들어오고,
이제 **문제를 풀수록 펫이 3단계까지 자랍니다.**

- **바로 열기**: https://kateko0602.github.io/math-quest/
- **체험 PIN** — 학생 `1234` · **선생님 PIN은 첫 접속 때 4~6자리로 직접 정합니다** (코드·화면·README에 없습니다)
- 데이터는 이 브라우저에만 저장되는 **테스트 모드**입니다.
- 연습용으로 따로 쌓고 싶으면 주소 뒤에 **`?mode=demo`**를 붙이세요. 운영 데이터와 섞이지 않습니다.
- 예시 학생 이름·반 이름은 모두 샘플입니다.

## v1.0에서 달라진 점 — 3단계 (동기부여 + 클릭 초간소화)

| 영역 | v0.9 | v1.0 |
| --- | --- | --- |
| 하루 목표 | 연속 불꽃만 | **하루 3문제 미션** — 숙제·오답프린트·밀린문제 아무거나 3문제면 **+10코인**(1일 1회) |
| 주간 목표 | 없음 | **이번 주 5일 미션 → +30코인** · 작은 점 5개 게이지 |
| 복귀 | 없음 | **이틀 이상 쉬었다 돌아와 3문제면 +15코인** 응원 보너스 |
| 펫 | 간식(코인)으로만 성장 | **문제를 풀면 경험치** → **1단계 아기 → 2단계 성장 → 3단계 완성 + 칭호** |
| 채점 클릭 | 문제마다 ⭕/❌ | **🏫 대표문제(1,2,3…) 접기** · **🏫 몇 번부터 숙제?** · **홀수만/짝수만** · **✨ 나머지 전부 ⭕** |
| 질문 | ❌ 틀린 문제만 | **⭕ 맞은 문제도 ⭐ 질문** (엄마 도움받아 풀었거나 찜찜할 때) |
| 선생님 | 질문 TOP 5 | **⭐ 질문 TOP 5 · ❌ 많이 틀린 문제 TOP 5 · 📋 학생별 못 고친 오답** (선생님 화면 전용) |
| 빈 개념 쪽 | `58쪽 ?번` 타일 생김 | **문제 없는 개념 설명 쪽은 자동 제외** |
| 쪽수 입력 | 쉼표 붙여쓰면 한 문제로 | **`2,4,5,6`·전각 쉼표도 개별 번호** |
| 교재 고르기 | 한 쪽씩 | **📚 책 전체 보기** — 단원·쪽수 한눈에, [단원 전체] 한 번 |
| 효과음 | 아이폰에서 겹치면 띡끽 | **리미터 + 겹침 제한 + 짧은 간격 차단** |

## 동선 (아이는 5초 컷)

1. 반 → 내 이름 → PIN 4자리 (회원가입 없음)
2. **① 채점** — 수업에서 푼 부분은 `🏫 대표문제 접기` / `🏫 몇 번부터`로 접고, **틀린 것만 ❌** 누른 뒤 **`✨ 나머지 전부 ⭕`** 한 번. 맞았지만 궁금하면 `⭐`
3. **② 정리 · 사진** — 오답 `⚔️ 해결!(펫 알 부화)` / `⭐ 질문`, 오늘 뽑힌 1쪽 사진(미리보기 확인) → 제출
4. **③ 완료** — 폭죽 + 코인 + XP + 미션 달성 + 보스 데미지

## 화면

- 아이: **숙제**(오늘 미션 카드 · 오늘 숙제 · 오답프린트 · 밀린문제) · **내 도감**(펫 성장 단계 · 자주 하는 실수 · 못 고친 오답 · 불꽃 달력 · 칭호 · 단원평가) · **랭킹**
- 설정(⚙️): 캐릭터·닉네임, 소리, PIN 바꾸기, 이야기, 선생님 모드, 로그아웃
- 선생님(첫 접속 때 정한 PIN): **오늘** · **📊 반 대시보드**(제출률·오답 수정률 + 질문 TOP 5·많이 틀린 TOP 5·학생별 못 고친 오답) · **질문** · **성취도** · **⚙️ 관리**(진도·숙제·기한, 책 전체 보기, 프린트, 쿠폰, 쪽수표, 학생·PIN)
